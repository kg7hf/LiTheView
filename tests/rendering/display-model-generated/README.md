# Generated display-contract fixtures

The RGB, round and synthetic packed forms exercise target-free generation and native resource selection.
Synthetic R2 uses 512 by 384 logical emitters; synthetic red and red/yellow cells use 256 by 192 cells.
Each packed fixture requires 49,152 native frame bytes. These are software fixtures, not hardware descriptions.

Run `tools/check-display-definitions.ps1` against installed per-format packages. Run
`tools/check-target-feasibility.ps1` for separate surface and target-budget validation.
